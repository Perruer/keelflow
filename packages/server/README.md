# keelflow

Server and command line of [Keelflow](https://github.com/Perruer/keelflow): build AI agents and LLM workflows visually. Security-maintained continuation of Flowise.

```bash
keelflow start                      # web UI and API on http://localhost:3000
keelflow worker                     # queue worker (MODE=queue)
keelflow user <email> <password>    # reset the owner's password
```

Configuration: see [.env.example](https://github.com/Perruer/keelflow/blob/main/packages/server/.env.example) and the [README](https://github.com/Perruer/keelflow#readme).
