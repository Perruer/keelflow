# Keelflow API docs

Swagger UI for the Keelflow REST API.

1. Start Keelflow from the repository root: `pnpm start`
2. In another terminal: `cd packages/api-documentation && pnpm start`
3. Open http://localhost:6655/api-docs

Requests from the docs page need an API key: create one under **API Keys** in Keelflow.
